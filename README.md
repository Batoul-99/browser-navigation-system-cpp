# Browser Navigation Management System - C++

A C++ Data Structures academic project that simulates core browser features such as page history, bookmarks, and related pages using linked data structures.

## Project Overview

This project implements a simplified browser navigation and bookmarks management system. It focuses on using dynamic memory allocation, pointers, singly linked lists, and doubly linked lists to manage browser-like data efficiently.

## Features

- Parse page, bookmark, and related-page data from an input text file
- Store browser history using a doubly linked list
- Store bookmarks using a doubly linked list
- Store related pages using a singly linked list
- Open or create new pages with related pages
- Search browsing history by URL substring
- Delete pages from history and bookmarks
- Remove history older than a specific date
- Find the most related page
- Return the most recently visited bookmarks
- Remove the least visited bookmark
- Write updated data back to a text file
